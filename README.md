# Github-Tutorial

A small hands-on project used to learn and demonstrate core Git and GitHub workflows — branching, committing, merging, and resolving conflicts.

## Contents

- `main.py` — sample Python script used to practice commits, branching, and merge-conflict resolution.
- `Github_Leitfaden.pdf` — reference guide covering Git/GitHub fundamentals.
- `Seminarkurspräsentation.pdf` — accompanying seminar course presentation.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mxlu42/Github-Tutorial.git
cd Github-Tutorial
```

Run the sample script:

```bash
python main.py
```

## Purpose

This repository is a learning exercise rather than a production application. It's used to practice:

- Creating and switching branches
- Committing incremental changes
- Merging branches and resolving conflicts
- General Git/GitHub collaboration workflows
